# Content review

All bundled first-aid, survival and food-safety content is marked **pending review**, and each
article in the app says "Not yet clinically reviewed". It was written conservatively from the
publishers cited in each article, but **no qualified reviewer has checked it yet**.

An article may be marked reviewed only when every step below is done by a qualified person
(for first aid: a doctor, paramedic or certified first-aid instructor).

## Checklist for each article

- [ ] Open every cited reference and confirm the current version is used. Replace any URL that has moved.
- [ ] Each instruction matches the cited guidance, including order of actions.
- [ ] The most important actions come first and are numbered.
- [ ] "Do not" items are correct and include relevant local practices to avoid.
- [ ] Warning signs and when to call 112 are complete.
- [ ] No medicine doses, unless the source gives them and they are safe for lay rescuers.
- [ ] No folk remedies or unsafe shortcuts.
- [ ] Wording is short, plain and readable under stress.
- [ ] Indian context checked: numbers (112, 1033), common hazards (snakes, heat, floods, rabies).
- [ ] Limits are stated (training, children and babies, pregnancy).

When done, set in the source file (`tools/content/*.py`):

```python
"review": {"status": "reviewed", "reviewedBy": "<name, qualification>", "reviewedOn": "YYYY-MM-DD"}
```

then run `python3 tools/content/build_guides.py`. The build fails if "reviewed" is set without a
reviewer and date.

## Items that need specific checking

- CPR depth and rate (5–6 cm, 100–120/min) against current AHA/ERC guidance.
- Choking sequence (back blows then abdominal thrusts) against the guidance used in India.
- Tourniquet wording in Severe bleeding.
- Heatstroke cooling methods against the NCDC heat action plan.
- Boiling time at altitude and solar disinfection times against WHO/CDC.
- National highways helpline number 1033.
- Retained-heat cooking safety guidance.
- Every NHS URL (`nhs.uk/conditions/...`): confirm the page exists and matches.
